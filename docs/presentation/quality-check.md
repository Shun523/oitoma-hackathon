- 全ページ16:9、淡い背景・濃い文字、強調色は緑と橙の2色。
- 結論タイトル32〜40pt、本文と図のラベル24pt以上。ページ番号等のメタデータのみ11〜12pt。
- 列挙は最大3項目。長い説明・制約・専門的な補足はノートへ配置。
- 本文、図形、矢印はPowerPointのネイティブ要素で編集可能。ストック画像・装飾アイコンは使用していない。
- 技術図はスライド3が5ノード、4が通信3＋処理5ノード、10が主要4＋保存先1ノード。複雑な実装全体を1枚へ集約していない。

## 技術整合の確認と修正

| 項目 | 完成版での扱い |
| --- | --- |
| 生成処理の責務 | 話題抽出・候補化・順位付け・要約はおいとま、進行と人数調整はブラウザ、キーとJSON検証はNext.js API。実装と照合 |
| 不足者の再処理 | ④の不足者だけ③を再実行する点をスライド4に表示。補充フラグと確認工程をノートに説明 |
| 共有タグの人数制約 | 上限を厳密保証としない。候補再追加等の補充経路があるため、全経路の下限保証も本編では主張しない |
| AI出力の正確性 | JSON検証は意味内容の正しさを保証しない。主催者が確認・修正する工程を表示 |
| 1人追加 | extract・rank・assignと、既存結果を保つ実装を照合。「2タスク」は再試行を含む実通信2回の保証ではない |
| 最新の運用方針 | 2026-10-14のngrok方針を優先。古いVercel構成を現在の構成として図示しない |
| 個人情報 | 名前「欄」を除外する実装であり完全匿名化とはしない。同意列がない場合のデモ仕様、localStorage等の暗号化未確認、おいとま原本規程未提供をノートに明記 |
| 外部通信・認証 | ngrokでは学外中継があると本編にも表示。アプリ内認証やトンネル開設済みを主張せず、運用手順・稼働未確認と表示 |
| 架空例 | スライド2に明示。実回答・実出力として扱わない |
| 数値の出典 | 98テストは今回の実行、18項目と40人120枚のPDFは2026-10-12のmock検証記録。live生成時間や会話効果の数値を作らない |
| 初版の表示不備 | 入力例・図ラベルの改行、本文の配置、数値ボックスの高さ、結果カードの余白を調整し、再レンダリング後に再検査 |

今回、既存アプリの `npm test` を実行し、17ファイル・98テストが成功した。アプリ本体・依存設定は変更していないため、追加の機能テストや本番ビルドは行っていない。live API・実回答・ngrok・実紙印刷は今回の資料生成では使用していない。

必須要素の省略はない。資料から確認できない性能・効果・サービス側の保証条件は、未確認のまま区別している。
